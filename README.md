## Final Conclusion
We tested the original Stanford website and our redesigned prototype with five participants using think-aloud sessions. all five found the prototype cleaner and easier to scan and most praised its clear call to action buttons and consistent visual design. However all five also felt it offers less detail than the original and some missed search or filters and clearer link labels such as Overview.

Based on this qualitative data, the prototype partially improved the user experience. It improved first impressions, visual clarity and the visibility of key actions but it did not match the originals depth of information. A future version should keep the cleaner layout while adding richer content, filters and more descriptive link text.
